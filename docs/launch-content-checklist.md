# Launch content checklist

The production footer reads contact and social information from `src/config/site.ts`. Empty values are intentionally omitted from the live website.

Before launch, Haribol Lubes Limited should verify and provide:

- public telephone number
- WhatsApp sales number, including country code
- public sales or enquiries email address
- Facebook profile URL
- Instagram profile URL
- LinkedIn company-page URL
- X profile URL, if actively maintained

Only approved public details should be added. After updating `siteConfig`, verify every telephone, WhatsApp, email and social link on desktop and mobile.
